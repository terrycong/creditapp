# 🎯 抽奖系统业务流程文档

> 家庭积分系统 - 幸运抽奖模块用户操作指南

---

## 📋 概述

抽奖系统允许家长创建抽奖活动，小孩使用积分参与抽奖赢取奖励。系统采用主题 + 奖池模式，支持多种抽奖类型和概率配置。

---

## 👨‍👩‍👧‍👦 家长端操作流程

### 1️⃣ 创建抽奖主题

```
进入抽奖管理页面 → 点击"创建主题" → 填写以下信息：
```

| 字段 | 说明 | 示例 |
|------|------|------|
| 主题名称 | 抽奖活动的名称 | "周末幸运大抽奖" |
| 描述 | 活动详细说明 | "完成任务即可参与，赢取丰厚奖励！" |
| 每次消耗积分 | 参与一次抽奖需要的积分 | 50 积分 |
| 抽奖类型 | 概率计算方式 | 固定概率/动态概率 |
| 启用状态 | 是否对小孩可见 | 启用/禁用 |

### 2️⃣ 添加奖品到奖池

```
选择主题 → 点击"添加奖品" → 填写奖品信息：
```

| 字段 | 说明 | 示例 |
|------|------|------|
| 奖品名称 | 奖品的描述 | "额外游戏时间 30 分钟" |
| 奖品价值 | 奖品对应的积分值 | 100 积分 |
| 库存数量 | 奖品可被抽中的次数 | 5 个 |
| 概率权重 | 中奖概率权重（数字越大几率越高） | 10 |

### 3️⃣ 管理抽奖活动

- ✅ **查看**：浏览自己创建的所有抽奖主题
- ✏️ **编辑**：修改主题信息或奖品配置
- 🗑️ **删除**：删除不需要的主题或奖品
- 🔄 **启用/禁用**：控制主题对小孩的可见性

## 👶 小孩端操作流程

### 1️⃣ 浏览抽奖活动

```
进入"幸运抽奖"页面 → 查看所有已启用的抽奖主题
```

- 查看每个主题的奖品池预览
- 查看每次抽奖所需积分
- 确认自己的积分余额是否充足

### 2️⃣ 参与抽奖

```
选择主题 → 点击"立即抽奖" → 确认消耗 → 等待结果
```

**流程说明：**

1. 系统检查积分是否充足
2. 弹出确认对话框（显示消耗积分）
3. 点击确认后进入抽奖动画（约 1-2 秒）
4. 显示抽奖结果（中奖/未中奖）
5. 自动更新积分余额

### 3️⃣ 查看抽奖结果

| 结果 | 说明 | 积分变化 |
|------|------|----------|
| 🎉 中奖 | 获得奖品对应的积分 | `-消耗 + 奖品价值` |
| 😅 未中奖 | 无奖励 | `-消耗` |

### 4️⃣ 查看历史记录

- 查看个人所有抽奖记录（最近 10 条）
- 显示每次抽奖的时间、主题、消耗和收益
- 支持按时间范围筛选

## ⚠️ 业务规则

### 积分规则
- 抽奖前必须校验小孩积分余额 ≥ 消耗积分
- 抽奖完成后立即扣除消耗积分
- 中奖后即时发放奖品积分

### 库存规则
- 奖品有库存限制，抽完后可能影响后续概率
- 家长可随时补充库存

### 权限规则
- 家长只能管理自己创建的主题和奖品
- 小孩只能看到 `active=true` 的主题
- 抽奖记录按小孩 ID 隔离

### 状态规则
- 主题禁用后，小孩端不再显示
- 已进行的抽奖记录不受主题状态影响

## 📊 数据实体关系

```
LotteryTheme (抽奖主题)
├── id: Long
├── name: String (主题名称)
├── description: String (描述)
├── pointsPerDraw: Integer (每次消耗积分)
├── type: LotteryTypeEnum (抽奖类型)
├── active: boolean (是否启用)
├── createdBy: User (创建者 - 家长)
├── prizes: List<LotteryPrize> (奖品列表)
└── lotteryDraws: List<LotteryDraw> (抽奖记录)

LotteryPrize (奖品)
├── id: Long
├── name: String (奖品名称)
├── value: Integer (奖品价值)
├── quantity: Integer (库存数量)
├── probabilityWeight: Integer (概率权重)
└── lotteryTheme: LotteryTheme (所属主题)

LotteryDraw (抽奖记录)
├── id: Long
├── theme: LotteryTheme (抽奖主题)
├── child: User (参与小孩)
├── pointsCost: Integer (消耗积分)
├── drawAt: LocalDateTime (抽奖时间)
└── results: List<LotteryDrawResult> (中奖结果)
```
